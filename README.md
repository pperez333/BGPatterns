# BGPatterns
Database of board game mechanics patterns

Considering **board game mechanic's** like **software design patterns** is a useful way to think about game design: each mechanic is a reusable solution to a recurring gameplay problem, with known strengths, weaknesses, and typical use-cases.
For the time being, this list uses the following template, to change with time:
- Name
- Core idea
- What problem it solves
- How it creates decisions
- Typical player experience
- Common variants
- Strengths
- Weaknesses / risks
- Games that use it
- What it combines well with
- Failure modes / anti-patterns

The catalogue with the initial patterns is in https://github.com/pperez333/BGPatterns/wiki/Catalogue.
